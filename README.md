# Transformer 简介

Transformer 是一种以注意力机制为核心的深度学习模型架构，最初被提出用于机器翻译任务，后来迅速扩展到自然语言处理、计算机视觉、语音识别、多模态理解与生成式人工智能等领域。与传统循环神经网络（RNN）或长短期记忆网络（LSTM）按顺序处理序列不同，Transformer 通过自注意力机制并行建模序列中不同位置之间的依赖关系，因此更适合在大规模数据和现代硬件上高效训练。

Transformer 的核心组件包括多头自注意力、前馈神经网络、残差连接、层归一化和位置编码。自注意力机制会根据查询（Query）、键（Key）和值（Value）计算序列内部各元素之间的相关性，使模型能够动态关注对当前任务最重要的信息；多头注意力则从多个表示子空间同时学习不同类型的关系。由于注意力本身不包含词序信息，模型通常会引入位置编码或相对位置表示，帮助网络理解序列顺序。

在典型结构上，Transformer 可以分为编码器、解码器以及编码器—解码器三类形态。编码器结构擅长文本理解和特征提取，例如分类、检索、命名实体识别等任务；解码器结构适合自回归生成，被广泛用于大语言模型；编码器—解码器结构则常见于翻译、摘要和问答等输入到输出的序列转换任务。不同任务会根据需求选择合适的结构，并结合预训练、微调、指令对齐等方法提升实际效果。

Transformer 的优势在于并行计算能力强、长距离依赖建模效果好、可扩展性高，并且能够通过扩大数据、参数规模和训练算力持续提升性能。不过，它也存在计算和显存开销较大、长序列处理成本高、训练数据质量敏感等问题。实际应用中通常会结合稀疏注意力、低秩适配、模型量化、检索增强生成（RAG）以及蒸馏等技术，在性能、成本和部署效率之间取得平衡。
