# YOLO 算法简介

YOLO（You Only Look Once）是一类经典的单阶段目标检测算法。与需要先生成候选区域再进行分类的两阶段检测方法不同，YOLO 将目标定位和类别预测统一为一次端到端的回归任务：模型只需对输入图像进行一次前向传播，就能同时输出目标的边界框位置、置信度以及类别概率。因此，YOLO 通常具有较高的检测速度，适合实时视频分析、自动驾驶感知、工业质检和安防监控等对时延敏感的场景。

YOLO 的核心思想是把图像划分为若干网格，并由网格中的预测单元负责检测落入该区域的目标。模型会为每个目标预测边界框坐标、目标存在的置信度和类别信息，再通过非极大值抑制（NMS）等后处理方法去除重复框，得到最终检测结果。随着版本演进，YOLO 系列算法不断引入更强的特征提取网络、多尺度特征融合、更合理的标签分配策略和更高效的训练技巧，在速度与精度之间取得了良好平衡。

总体来说，YOLO 的优势在于检测流程简洁、推理速度快、工程部署友好；不足之处是对于极小目标、密集遮挡目标或复杂背景下的目标，检测效果可能受到影响。实际应用中通常需要结合数据增强、模型剪枝、量化加速以及针对业务场景的数据微调，进一步提升 YOLO 模型的稳定性和部署效率。
